# 耄耋哈气 Tap

这是一个独立重写的全屏互动网页，保留了“隐藏分区、节拍量化、拖动连续触发、Canvas 几何特效”的玩法，但没有复制原项目代码。

## 运行

```powershell
py -3 -m http.server 8000
```

在浏览器打开 `http://localhost:8000`。

## 素材说明

- `assets/maodie-calm-head.png` 和 `assets/maodie-hiss-head.png` 分别从两张原图裁成透明圆头素材，统一处理到 `1024×1024`。
- 所有触发区统一播放本地 `assets/maodie-haqi.mp4` 中的哈气片段，并通过 Web Audio 形成四档固定音阶；浏览器无法解码时才回退到媒体元素或合成声。
- 原始图片来源和许可状态记录在 `assets/SOURCE.md`；它适合个人本地 Demo，公开发布前应确认原作者授权。

## 哈气音阶

音阶实现参考 `MarkCup-Official/Dagou-Tap-New` 的固定半音变调思路，代码为独立实现。第三档保留原始音高，四档依次为：

| 分区 | 半音偏移 | 播放倍率 |
| --- | ---: | ---: |
| 横屏最左 / 竖屏最上 | +7 | 1.498307 |
| 横屏左二 / 竖屏上二 | +4 | 1.259921 |
| 横屏左三 / 竖屏上三 | 0 | 1.000000 |
| 横屏最右 / 竖屏最下 | -3 | 0.840896 |

倍率使用 `2^(半音数/12)` 计算，同一分区始终保持相同音高。

## 结构

- `index.html`: 页面结构与响应式样式
- `main.js`: 节拍器、音频合成、输入队列、Canvas 特效和猫咪动画
- `assets/`: 耄耋圆头状态图、哈气采样及来源说明
