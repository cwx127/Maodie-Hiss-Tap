# 耄耋哈基米 Tap

一个无需构建、打开即玩的全屏节奏互动网页。画面使用从绿幕素材中提取的耄耋圆头，点击隐藏九宫格即可组合 `哈 / 基 / 米` 三个采样及高、中、低三档音高。

  <img src="assets/maodie-greenscreen-hiss.png" alt="张嘴哈气的透明耄耋圆头" width="360">
</p>

## 功能

- `3 × 3` 隐藏触发区：三个音节乘以三档音高。
- 128 BPM 节拍量化：点击和拖动输入按八分音符顺序播放。
- 鼠标与触摸拖动：跨格时自动补全经过的分区。
- 数字键 `1–9`：按当前屏幕上的九宫格顺序直接触发。
- Web Audio 播放：三个 WAV 只存一份，运行时通过 `playbackRate` 变调。
- 媒体元素和合成音兜底：部分浏览器无法解码 WAV 时仍可发声。
- 绿幕透明素材：平静态与张嘴态使用同一段视频中的相邻动作。
- 点击反馈：切换张嘴图，叠加快速放大、轻微旋转、回弹和 Canvas 几何特效。
- 响应式布局：桌面、横屏手机和竖屏手机使用一致的九宫格逻辑。
- 音乐与音效可以分别静音，并支持 `prefers-reduced-motion`。

## 快速运行

项目没有 npm 依赖，也不需要构建。由于音频使用 `fetch()` 预载，请通过本地 HTTP 服务运行，不要直接双击 `index.html`。

```powershell
cd C:\Users\cwx\Desktop\Maodie-Hiss-Tap
py -3 -m http.server 8000
```

如果系统没有 `py` 启动器，也可以使用：

```powershell
python -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/>。

## 操作

| 操作 | 结果 |
| --- | --- |
| 点击或触摸 | 触发当前位置的音节与音高 |
| 按住并拖动 | 按经过顺序连续触发分区 |
| 长按同一区域 | 以固定间隔重复触发，并产生果冻抖动 |
| 数字键 `1–9` | 按九宫格从左到右、从上到下触发 |
| 音乐按钮 | 单独开关背景节拍 |
| 音效按钮 | 单独开关哈基米采样 |

## 九宫格映射

横屏时，行代表音节，列代表音高：

|  | 高音 | 原音 | 低音 |
| --- | --- | --- | --- |
| 哈 | `1` | `2` | `3` |
| 基 | `4` | `5` | `6` |
| 米 | `7` | `8` | `9` |

竖屏时，列代表音节，行代表音高：

|  | 哈 | 基 | 米 |
| --- | --- | --- | --- |
| 高音 | `1` | `2` | `3` |
| 原音 | `4` | `5` | `6` |
| 低音 | `7` | `8` | `9` |

## 音高设计

每个音节使用相同的三档相对音程：

| 档位 | 半音偏移 | 播放倍率 |
| --- | ---: | ---: |
| 高音 | +5 | 1.334840 |
| 原音 | 0 | 1.000000 |
| 低音 | -5 | 0.749154 |

倍率按照十二平均律公式计算：

```text
playbackRate = 2^(半音偏移 / 12)
```

当前实现使用 `AudioBufferSourceNode.playbackRate`，因此升调会同时变快、变短，降调会同时变慢、变长。这与参考项目的重采样听感一致。

## 音频流程

1. 页面加载时预取 `hakimi-ha.wav`、`hakimi-ji.wav` 和 `hakimi-mi.wav`。
2. 首次交互创建并解锁 `AudioContext`。
3. 三段采样解码成 `AudioBuffer`，按九宫格档位设置播放倍率。
4. 输入时间量化到 128 BPM 的八分音符网格。
5. 解码失败时回退到关闭保音高的 `HTMLAudioElement`；播放仍失败时使用合成音。

三段采样的截取位置、处理方式和来源记录在 [assets/SOURCE.md](assets/SOURCE.md)。

## 视觉流程

1. 从绿幕视频约 `17s` 和 `20s` 处选择平静态与张嘴态。
2. 根据绿色背景生成软透明蒙版并进行去绿处理。
3. 收缩边缘、清理半透明溢色，再放大到 `1024 × 1024`。
4. 两张 PNG 绝对定位叠放，仅切换上层张嘴图透明度。
5. 点击时使用欠阻尼弹簧驱动最大约 `22%` 的放大和轻微旋转。

没有使用 AI 重画猫脸，网页显示的是素材视频原帧。
