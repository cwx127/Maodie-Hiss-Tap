# 耄耋哈基米 Tap

这是一个独立重写的全屏互动网页，保留了“隐藏分区、节拍量化、拖动连续触发、Canvas 几何特效”的玩法，但没有复制原项目代码。

## 运行

```powershell
py -3 -m http.server 8000
```

在浏览器打开 `http://localhost:8000`。

## 素材说明

- `assets/maodie-greenscreen-calm.png` 和 `assets/maodie-greenscreen-hiss.png` 从绿幕视频原帧抠出，统一处理为 `1024×1024` 透明 PNG。
- `assets/hakimi-ha.wav`、`hakimi-ji.wav`、`hakimi-mi.wav` 是从素材合集第一段截取的三个短采样。
- 点击时切换到张嘴图，并使用欠阻尼弹簧做快速放大、轻微旋转和回弹。
- 原始图片来源和许可状态记录在 `assets/SOURCE.md`；它适合个人本地 Demo，公开发布前应确认原作者授权。

## 九宫格音阶

音阶实现参考 `MarkCup-Official/Dagou-Tap-New` 的固定半音变调思路，代码为独立实现。每个采样均有高、中、低三档：

| 分区 | 半音偏移 | 播放倍率 |
| --- | ---: | ---: |
| 高音 | +5 | 1.334840 |
| 原音 | 0 | 1.000000 |
| 低音 | -5 | 0.749154 |

横屏时三行分别为 `哈 / 基 / 米`，三列从左到右为高、中、低；竖屏时三列分别为 `哈 / 基 / 米`，三行从上到下为高、中、低。倍率使用 `2^(半音数/12)` 计算。

## 结构

- `index.html`: 页面结构与响应式样式
- `main.js`: 节拍器、音频合成、输入队列、Canvas 特效和猫咪动画
- `assets/`: 耄耋透明状态图、哈基米短采样及来源说明
